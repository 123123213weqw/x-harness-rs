# Plugin icon artwork

Seven XHarness workflow illustrations are repository-owned SVG artwork. GitHub uses the unchanged official Primer Octicons mark-github-16 path, scaled to fit the common plate. Source: https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg . MIT license retained in GITHUB-MARK-LICENSE.txt.

Shared 64px canvas, 60px rounded plate, pure white background and black ink, no gradient or shadow, no external fonts, raster dependencies, scripts or animation. Only the registry icon assets change; plugin ZIPs and capabilities remain untouched.

## Approved visual baseline

User-approved on 2026-10-03: all eight icons use pure black (#000000) ink on a white (#ffffff) rounded plate. Keep the current minimal geometry, no gradient, shadow, glow, or per-plugin colour. GitHub retains the official path and license. Future additions should follow this baseline. Visual approval does not publish registry assets or replace the desktop application.

New entries: original API angle-bracket, database cylinder and container-stack glyphs use the same monochrome geometry. Container artwork is not the Docker trademark/logo. These three new plugin packages are local beta candidates until publication.
