## 回归中修正的问题

1. 虚拟列表过去只保护输入控件焦点；按钮／原生 disclosure 获得焦点后，缩放可能卸载行，使自动折叠失去焦点保护。改为保护当前真实焦点所在行；焦点移走仍卸载，不引入永久 interaction pin。
2. 原滚动夹具的一次增长更新丢掉了 Assistant DTO 必填字段，可能进入未知节点 fallback；修正为保留合法 DTO，并增加真实增长高度断言。保留原有滚动门禁，双引擎重新通过。
3. ChatNodeStore 是稳定可变查询对象，而不是每次更新都会换身份的 Map；增加轻量 DOM 生命周期属性观察，并使用相同身份的查询对象进行浏览器回归，避免只在新建 Map 的测试数据下生效。
