# 工作集与增量压缩验收

本轮将工作集减载、只处理新原文的压缩、无收益退路及恢复兼容作为同一个交付目标。验收使用冻结的旧版和候选构建，在 V100 的独立目录运行真实 DeepSeek 编程任务；通过条件是可执行产物、范围控制和持久历史完整，不是模型自评或摘要生成成功。探索测试已经发现并修复真实问题；最终候选已完成固定系统前缀的对照。运行正确性、隐藏代码验收和压力门禁通过；严格输出格式门禁仍有失败，不标为全面通过，也未合并、发布或替换软件。

## 不变的对照条件

旧版生产源固定为 `e0a35e4c4b3af36ed0e1b0ef6f348800c298a872`。候选使用当前源码的完整独立快照。两组使用同一个实验桥、输入、模型、关闭思考配置和 32K 实验窗口；这不是对 DeepSeek 最大上下文的定义。所有 Rust 编译只在远端执行，不部署或重启已安装的软件。

每个构建前重新生成 `compaction_eval_source_manifest.json`，包含 Core、Context、Compaction、Session、JSONL、Provider、Tools、Interaction、Host App 的全部 Rust 源、生产 history 执行器和 Cargo 文件的字节 SHA。运行前先核对远端二进制 SHA，再核对二进制内嵌的完整源码指纹。新增模块自动纳入指纹；编译成功或文件名不同不能代替身份核验。验证不符时，在任何模型请求前退出。

## 真实编程任务

任务是 Python 多模块账目导入与报告，模型的 read/write 在专用工作目录内，固定 test 工具执行真实 Python unittest，history 使用生产实现。代码不是 mock 返回值，模型确实修改文件并执行测试。原生桌面、任意 bash 及跨平台安装包端到端行为不在该实验覆盖范围内。

隐藏测试位于 read/write 能力之外，且在模型工作结束后才安装。模型可读的公开测试不能被 write 工具修改。冻结阶段源码通过内容 SHA 比较，不依赖模型说“我没有改”。多轮历史保留通过每次 Compact 前后的原 JSONL 字节前缀 SHA 检查。

完整通过要求：实际失败曾被观察、四个工作轮次结束、至少三次持久摘要用于增量链路检查、当前公开测试及 23 项隐藏验收通过、阶段范围和最终只读边界遵守、当前事实正确、审计没有持久思考内容。跳过无收益可以是正确运行行为，但三次跳过不能冒充验证了三次增量摘要；这种样本会分别记载而不标成完整增量链路通过。

## 独立压力样本

压力测试与编程质量分开统计，不用合成源通过替代编码验收。

- 16K 实验窗口和较低压力阈值，实际读取长工具结果并运行只读诊断：检查无收益处理是否让仍能安全发送的任务继续，是否破坏只读范围。

压力窗口用于制造边界，不定义 provider 最大容量。禁止发布文字保留只是摘要保真度检查；发布能力由实验工具权限隔离，这不等同于证明任意 bash 环境的外部操作门禁已经实现。

## 运行入口

1. 同步已完成的当前源码到独立远端快照，排除 .git、target、node_modules、环境密钥和认证文件；生成 manifest。
2. 远端顺序构建旧版及候选；切换源码时触碰全部 Rust 文件，避免共享 target 的旧产物复用。使用 `--locked`，构建后再次核对 manifest 与实际源码字节，冻结二进制和 manifest，并回传 SHA。只核对内嵌 manifest 自洽还不足以发现构建过程改写 Cargo.lock。
3. `scripts/experiments/compaction-multiround.py run` 提供已核验二进制 SHA、manifest、全新远端和本地证据目录、arm、seed；`--mode stress` 单独运行压力测试。
4. `compare` 读取两组证据。相同源码指纹、缺控制组或重复标注的样本不能静默合并。

凭据从已有 Mac Keychain 读取，只经 SSH stdin 输入内存，不放进命令参数、环境变量、报告或原始思考审计。日志只使用公开合成任务内容；summary 事件元数据只保留摘要大小、SHA 和来源，不保存额外推理字段。

## 已实现的生产修改

- 工作集仅在实际压力下激活；闭合工具批次作为整体减载，原文仍在现有 history／工具结果池中。真实用户请求、未知结果、未闭合批次、opaque provider 状态和运行时控制不能被偷偷退休。只有实际提供 history 工具的运行器启用减载。
- 校准使用同一个完整请求的消息、schema、运行时注入和 guard 计数，不拿旧测量与新消息体积拼接。局部估算只决定选择；发送及摘要提交仍经过完整请求 admission。
- 旧 checkpoint 不进入新摘要。新原文叶子在独立的输入／输出预算内切分，没有额外模型合并，也不把已有摘要再次摘要。正文切分优先换行边界，保持 UTF-8 字节完整。
- 没有收益／没有合格源在软压力下有显式跳过终态，继续前重新预算；硬超限不绕过门禁。确定失败按完整指纹缓存，临时网络失败不缓存成永久无收益。原 journal 保持追加，不破坏源。
- 摘要候选经过完整预算检查后才用严格 CAS 原子提交；外部 revision 改变则丢弃候选。live／恢复／UI 共用终态语义，不再无限停在 Compact spinner。
- 当前用户请求后的可容纳工具批次组成有界 hot 工作簇；不是只保留最新一批。跨 read／test／reason 步骤的证据可同时消费，巨型结果仍可冷退。索引带有有界、确定性的最近批次回执，不推断工具成功。
- history 索引的退役节点 seq 范围只是审计范围，不是旧 checkpoint 底层原文的搜索下界；默认从整个会话检索，沿 next 分页。媒体证据只恢复类型化附件引用，不复制图片字节或私有 provider 元数据。
- 摘要候选及提交后 reload 保留显式 System；同时覆盖未使用 PromptAssembly 的 Core 调用者。有 PromptAssembly 的 Host 路径仍只有唯一固定前缀。
