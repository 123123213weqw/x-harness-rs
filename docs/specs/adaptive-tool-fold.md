# 工具过程的高度感知折叠

## 目标与边界

减少持续对话中工具卡片占据的页面空间。它是产品前端的展示策略，不是上下文压缩，不删除历史、Tool Arguments、Tool Result，不修改模型输入、轮数或执行状态；不增加 RPC 或工具注册。

## 职责

- Runtime 继续发布原有 Chat Node、递归工具状态、Turn Tail。
- `adaptive-tool-fold.ts` 负责纯函数资格检查和高度预算。默认预算为聊天可见高度的 40%，集中在 `TOOL_FOLD_VIEWPORT_SHARE`；展示设置统一为“自动 / 全部展开”。
- `use-adaptive-tool-fold.ts` 负责单个聊天的 ResizeObserver／MutationObserver、帧合并、浏览器交互保护及会话内折叠标识生命周期。
- `ChatNodeSeat` 按既有键控投影隐藏被折叠的重组件；轻量的展示状态仍由原有 Transcript State 保存。
- `TurnProcessSummarySeat` 复用原有轮次过程入口。运行中出现“已收起 N 个完成的操作”；点击可以展开／收起。完成后转为原有整轮过程入口，最终回答仍留在外面。

## 运行中规则

1. 只考虑 Turn 状态为 open、没有有效 Turn Tail 的 Tool 根节点。Session running 短暂变为 false 不是轮次结束信号。
2. 按较早优先折叠，始终保留最新工具根。仅根和递归子调用均已结束、均无错误时才可折叠。
3. 运行中、递归等待子调用和失败工具保留。错误暂不推断“已经恢复”；保守保留所有已报告失败。
4. 当前焦点、非空文本选择、阅读滚动锚点不被自动移除。用户点击展开的工具／原生 details，在当前会话内免于运行中自动折叠；这不产生永久虚拟列表挂载固定。
5. 用户明确展开整轮过程后，后续更新和缩放不再自动收起该轮；这一选择延续到 Turn Tail 到来。用户主动点击收起仍可收起。
6. 折叠保持粘性，放大窗口不会自动反复展开／收起。隐藏、零高度或无 ResizeObserver 的视图不作推测性折叠。
7. 虚拟列表保持原有约束：已挂载行使用真实布局高度，离屏行使用现有占位高度估值，绝不为了精确测高先全量挂载。单个最新或受保护工具超过预算时允许超出；预算不是强制裁切。
8. 占用正文／思考的大块不在运行中自动隐藏；已有 Turn Tail 整轮折叠继续处理已结束过程。

## 结束、恢复与资源生命周期

- 只有有效且属于本轮的 Turn Tail 才触发既有整轮默认折叠；无效／外轮 Tail 失败开放。
- 即使 Tail 已到来，失败或递归未结束的工具仍不得被隐藏。审批与问题的交互组件独立于过程区域，不纳入折叠。
- 自动标识和手动选择只存在于当前视图，不写持久化对话。刷新／重开：按设备保存的展示模式应用默认值；自动模式已结束轮按 Tail 默认收起，运行中轮重新按高度判定；不声称跨刷新持久化手动展开。
- 切换 session 时隔离数值相同的 turn id，清空自动显示标识；关闭或移出窗口的轮次释放其自动工具标识。
- 卸载时取消待执行 RAF，断开 ResizeObserver／MutationObserver 并移除 click/focus/selection 监听。

## 回归

- `node scripts/test-adaptive-tool-fold.mjs`：预算边界、各类保护、最新根、轮次隔离、非法高度、递归状态、历史不变、结束时 pending/error 不隐藏。
- `node scripts/test-turn-process.mjs`：原有 Turn Tail、最终回答、空／图像回答及实时与重放语义。
- `UI_TEST_DEPS=<Playwright 依赖目录> UI_TEST_BROWSER=chromium node scripts/test-turn-process-browser.mjs`，WebKit 同样执行：实际 React、工具组件、虚拟列表；80 个工具折叠、恢复、手动覆盖、缩放、焦点、文本选择、原生 details、观察器释放及数据不变。
- `node scripts/assemble-static-ui.mjs` 生成安装版/Web 共用的受管静态产物；禁止只改旧 bundle 而不改源模块。

## 统一展示设置

- 仅两档：`auto`（自动，默认）、`expanded`（全部展开）。设置、单卡片、思考、整轮和运行中高度折叠使用同一份共享策略，不再独立解释四个旧档位。
- 自动：单卡片默认收起；已结束过程默认整轮收起；运行中只按高度折叠成功的旧工具，保留最新、等待、错误与交互保护。
- 全部展开：禁用运行中高度折叠，已结束整轮与 Tool/Think 详情默认展开；仍采用窗口化，离屏重组件不强制挂载。不改变各工具内容预览上限。
- 手动展开／收起优先于当前模式的默认值，不被流式更新、缩放、窗口卸载重新覆盖；明确切换全局模式时重新应用新模式默认值，包括之前未挂载的详情。手动整轮展开自动模式中仍优先。
- 保留原 localStorage 键 `xharness.ui.process-mode.v1`：旧 compact/standard/detailed 迁到 auto，verbose 迁到 expanded；未知值、缺失值回退 auto。页面加载时保存规范化值，无需删除其他偏好。
- 移除按旧 compact CSS 隐藏思考的特殊分支；使用统一的披露/整轮呈现。设置可中文/英文显示，快捷键在两档间循环。
- 不新增后端协议，不修改审批策略，不删除或压缩上下文/持久化历史。
