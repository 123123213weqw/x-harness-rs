# 历史只读偏移索引（HISTORY-02a）

## 目标与非目标

减少已恢复、闲置长会话每次 `session.history` 分页时的完整 JSONL 重放。
本阶段只优化历史查看，不修改模型上下文、Agent 恢复、工具执行、Inbox、审批、问题或 Goal 的恢复依据。

**原 JSONL 始终是唯一权威数据。** 不截断、不删除、不重写聊天原日志，不构造可执行的“部分 Session”。
本规范描述第一阶段索引。随后已实现 `HISTORY-02b1` 的 [闲置恢复快照](idle-recovery-checkpoint.md)；活动任务加速仍待独立验收。

## 职责边界

- `xharness-session`：可选 `Store::history_window` 和只读 `SessionHistoryWindow`。默认返回 `None`，已有 Store 实现无须改变。
- `xharness-session-jsonl`：版本化 `<id>.history-index`，定位物理批次，受限读取、校验、释放旧内嵌审计快照。
- `xharness-projection`：复用完整历史使用的提示来源、块折叠及终端卡片投影逻辑；不在 Store 里生成 Web JSON。
- `xharness-host`：仅在会话已恢复、当前不运行且权威序号匹配时采用索引；RPC 方法、事件字段和分页游标不变。
- 已有匹配序号的内存权威快照时，优先保留原缓存读取路径；不为了使用索引而重新读取磁盘批次。回退路径会照常验证文件指纹，缓存只是路径选择提示。

## 生成与校验

完整日志经过原有 `Session::restore` 校验成功后，尽力写出旁路索引。索引包含：

1. 版本、会话 ID、原文件格式、Header 长度、`next_seq` 和文件指纹。
2. 每个物理批次的偏移、长度、revision、序号范围和 SHA-256。
3. 可分页消息序号，以及跨页投影需要的 Inbox 来源、Compaction 起点、ToolCall 与已完成模型步骤。
4. 整份索引元数据的 SHA-256。

读取前验证文件身份/长度/时间及头尾采样指纹，检查元数据摘要、连续偏移、连续序号、revision 和整数边界；选中的批次另验 SHA-256。读取结束再次检查文件指纹。
这些摘要是损坏检测，不是抵御同用户恶意修改的数字签名。

写出采用既有会话进程锁、跨进程文件锁、同目录临时文件、同步及原子替换。
只对正常 `.jsonl` 发布；压缩维护临时文件、未完成的尾部、语义校验失败均不发布。
索引发布失败不影响正常日志读取。删除会话时一并删除旁路索引。

## 分页与完整性

- 保持原先以 UserMessage / AssistantMessage / ToolResult 计数的分页边界。
- 工具结果页可单独定位此前 ToolCall；用户消息保留附件/来源元数据；Compact 替换保留来源命令。
- 已完成模型步骤的历史 chunk 仍折叠；中断的正文与思考仍完整保留、按原规则合并。
- 旧内嵌 RequestHeader 审计每批校验后立即释放，不先堆积整页快照；完整审计仍由既有按需接口读取。

## 内存边界与回退

- 旁路索引最大 8 MiB；构建采用保守估算及 100,000 条目上限。
- 单次索引分页的物理/展开读取合计预算 32 MiB。压缩记录先检查声明的展开长度，再解压。
- 预算按每个读取批次的 `max(物理字节, 展开字节)` 累加；这是读取工作量边界，**不是进程 RSS 的 32 MiB 硬上限**。反序列化对象、可见文本、投影 JSON 和运行时均有额外开销。
- 超界、未知版本、缺失、过期、损坏、非普通文件、并发变化均返回 `None`，Host 走既有完整重放路径。
- 以上是**优化路径上限，不是聊天内容上限**：绝不将大页截短或把回退误报为“无历史”。
- 未增加 `unsafe`、原始指针或内存映射；复用已存在的平台文件原语。

## 本阶段仍有的限制

仅靠第一阶段索引，首次冷会话 Hydrate 仍完整恢复。第二阶段有效闲置快照已可绕过这次物化；没有快照、活动工作或不支持的尾段仍完整恢复，不能把所有峰值都视为已消除。
索引在完整解析时生成；缓存命中不重建。日志追加或压缩后会使旧索引失效，下一次成功完整解析才重建。
运行中的会话及大批次超预算时继续走旧路径；该路径的原有峰值内存风险仍需恢复快照/旧审计迁移分别解决。
不承诺所有历史、所有平台均获得相同比例的性能收益。

## 回归与发布门禁

远程 Rust 回归覆盖所有分页游标、空页、越界游标、重启、追加/压缩失配、坏/超大索引、发布失败、符号链接、破损尾部、语义损坏和并发追加。
Host 回归比较索引与完整重放的完整 RPC JSON，并检查跨页工具卡片、来源、附件、Compact 和思考/正文块。
无索引或运行中的会话必须实际进入权威回退；读取不得启动模型任务。

性能测试只使用隔离合成日志：`history_index_performance_acceptance` 默认忽略，显式在远程执行。
用 `fixture` 生成，再在不同进程运行 `full` / `indexed`，比较页面摘要与 `/usr/bin/time -v` 峰值 RSS。
合成 Linux 数据不能代替 Mac/Windows 安装实例验收；通过跨平台 CI 和真实历史验收后再发布。

## 与 Compact 投影、Profile 统计联合验收（2026-10-01）

- 历史索引版本升级为 v2：自动压缩终态页除开始锚点外，按需读取摘要及替换消息的来源事件；旧 v1 索引视为缓存未命中，完整日志仍是权威来源，不修改历史。
- 实时、完整历史、偏移索引分页统一调用来源事件投影。终态页缺少开始／摘要节点时仍能展示完整成功摘要；失败终态保持隐藏，不残留运行状态。
- 闲置恢复检查点保留完整增量指标折叠状态；恢复记录的 `catalog_metrics` 为 `None`，只在未恢复的冷记录上使用只读统计缓存。
- 增加重启与 gzip 压缩后的跨批次来源回归，以及只包含终态事件的投影等价测试。
