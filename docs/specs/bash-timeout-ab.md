# 前台 Shell timeout_ms 严格解析单变量实验

基线：PR #196 `446a34b`。唯一生产变更：显式负整数不再被当作缺省 timeout。保留描述、Schema、120 秒默认、600 秒上限、背景 Job 分支、返回结构和其它工具。

## 验收

1. 同一确定性契约测试：旧版明确失败，新版非法参数无 spawn、合法参数行为保持；既有三 crate 回归不退化。
2. DeepSeek 与 V100 Qwen 27B 各自 A/B，固定模型配置，不跨模型合并均值。普通编程与强制非法参数恢复分开统计。
3. 独立验收产物、既有测试和修改范围，不信模型自述；每臂独立工作区、会话。原始请求与工具轨迹保留，Definitions 完全一致。
4. 两个模型每任务类型两对，A/B、B/A 交替，最多 16 次／60000 DeepSeek 未缓存输入。保护限制对两臂一致且仅用于实验。
5. 必须先检查非空源 manifest：两臂仅一个生产 Rust 文件不同；运行后复查。Rust 编译／检查／测试仅在服务器。
6. 错误拒绝与恢复按正确性判断，不要求故障探测快于“忽略非法参数”；自然任务性能不稳定则报告无性能证据，不扩大样本追求胜出。

本轮结果见 [双模型完整报告](../reports/bash-timeout-ab-20261003.md)。不自动部署／替换软件，不修改 PR #196。
