# 会话归档、恢复与永久删除

- `workspace.archiveSession` 仅把会话从活动列表移到归档，不删除日志或附件。
- `workspace.unarchiveSession` 恢复**同一个**会话 ID 和历史，不复制成新会话。
- 归档会话统一放在「设置 → 归档会话」管理；Tasks 侧栏只展示活动会话。
- 设置页按项目分组，支持搜索、项目筛选、排序、逐条恢复/删除、批量恢复/删除。批量删除仍逐条调用 `session.delete`，先确认再执行；部分失败须保留失败项并显示错误，不得假装原子成功。
- `session.delete` 仅接受已归档、空闲、无待执行/定时工作、无活动目标且没有子会话的会话。父子会话须先删除子会话。前端二次确认。
- 删除先向 Host Control Log 写入持久 tombstone，再清除会话 JSONL、索引、工具输出归档及会话附件。若磁盘清理中断，下次启动按 tombstone 重试；旧 ID 不得复活。
- 独立调试日志、备份和 Full 模式下的共享内容寻址 request-audit 快照**不由此操作清除**。这些数据可能被其他会话引用，不能按单个会话盲删。UI 必须明确告知此范围；若将来要求严格数据擦除，需实现跨会话引用追踪和审计快照 GC。

验收：同 ID 恢复、活动会话拒删、父子顺序、重复删除/重启清理、附件与归档清理、前端二次确认和错误回显。
