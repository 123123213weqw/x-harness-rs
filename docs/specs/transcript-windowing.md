# 历史消息 DOM 有界窗口化

## 范围与数据边界

只改变前端重组件的挂载，不删除历史、不裁剪模型上下文、不改变工具执行。
每个消息保留稳定的轻量锚点与订阅，继续复用 ChatView 的加载历史、底部跟随和分页锚点。
实现位于 `ui/overrides/transcript-windowing.js`，工具呈现状态接线由
`scripts/patch-transcript-row-state.mjs` 维护，并纳入重建与静态资源指纹。

## 首次渲染与宽度变化

- 未测量消息先显示占位，默认估算高度 240px；不为测量挂载完整 Markdown、代码或工具卡片。
- IntersectionObserver 前后各一屏缓冲，仅近屏消息逐步挂载，ResizeObserver 更新实测高度。
- 稳定行已经测得的高度在离屏时复用。宽度变化后离屏高度暂作估算，仅近屏行重新测量；禁止全量重挂。
- `overflow-anchor:none` 时，控制器保留可见锚点或底部位置并补偿测量差异；原生锚点启用时不重复补偿。
- 原始滚动总高度可以因估算修正而变化，不承诺未读取消息的精确高度。当前可见锚点、首次底部定位与分页锚点需要回归。
- 运行中最后的 live tip 与仍在执行的工具保持离屏挂载，确保结算及 Computer 隐私提示的 effect 完成；已完成的历史工具不因为属于同一长轮次而永久常驻。
- 无 ResizeObserver/IntersectionObserver 或无滚动容器时显式退回完整渲染，正常现代 WebKit 不走这个路径。

## 重组件之外的交互状态

- 稳定行持有轻量状态 Map，通过 React Context 提供给可卸载子组件；按消息行隔离，工具调用再按 callId 隔离，思考块按稳定块索引隔离。
- 已接入工具通用卡片、Bash、思考、Compact、注入上下文、命令卡片、Diff 展开、Computer 和 Cordis 展示状态。
- 不缓存 React 子树、DOM、工具结果全文或异步任务；状态只保存展示选择与由组件声明的轻量草稿。
- 普通点击、键盘操作或按钮焦点不永久保留消息。展开状态在离屏卸载后恢复，且不会被 Compact 展示偏好的挂载 effect 覆盖。
- 真正获得焦点的输入框／编辑区与已有文本选择临时保留，失焦或清空选区后释放。原生 details 的展开状态也保存在行外。
- 自定义工具如有需跨卸载保留的局部状态，应接入同一状态 API；审批／问题的业务请求仍由原运行时管理，不能搬入展示缓存。
- 行被删除或对话组件卸载时释放行状态；不新增磁盘或跨会话偏好持久化。监听器、观察器、动画帧在最后一行移除后清理。

## 验收

`scripts/test-transcript-windowing.mjs` 使用实际打包 React、ChatView 与工具组件：

- 350 行、每行 40 行代码的首次窗口化提交不全量挂载；连续宽度变化不会产生全量挂载峰值。
- 完整数据与所有轻量锚点保留；近屏校正高度，底部跟随、历史阅读、新消息追加及前插历史锚点正确。
- 工具与思考手动展开、原生 details、输入草稿离屏后恢复；不同调用互不串状态。
- 同一工具树中的多个 Cordis 卡片按 callId 分别保留展开状态和 client/host 源码标签；覆盖多次离屏卸载及旧版状态补丁升级。
- 输入焦点／选区保护及释放、活动节点结束、对话卸载和重新挂载。
- `scripts/test-transcript-row-state.mjs` 校验四类注册器、严格锚点、补丁幂等与产物指纹。
- Chromium 与 WebKit 均执行；Rust 编译若有需要仍只能在服务器执行，本改动不涉及 Rust。

## 限制

保留 O(N) 轻量锚点与已加载数据，不等同于限制当前会话的数据缓存。
单条可见超长消息、正在编辑的消息仍可能很大。原生查找／全选仅覆盖已挂载正文，全文检索应走数据层。
DOM 与 Chromium JS heap 对照不能换算成 macOS WKWebView footprint；真实安装包仍需另行验收。
