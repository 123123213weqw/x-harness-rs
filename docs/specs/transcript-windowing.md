# 对话历史 DOM 窗口化

## 范围

只卸载远离视口的历史消息组件，不删除前端历史事件，不修改后端对话、模型上下文或持久化。
使用现有 ChatNodeSeat / ChatView，不引入第二套消息投影。产品代码保存在
`ui/overrides/transcript-windowing.js`，由严格锚点补丁接入并写入 UI 构建哈希。

## 实现

- 保留每条消息原来的锚点和轻量外层元素；远处内容替换为实测高度的空占位。
- IntersectionObserver 共享于滚动容器，前后各保留一个视口高度；滚动范围更新按帧合并。
- ResizeObserver 共享于容器，用实际高度处理代码换行、工具展开和图片。原样式的 `:empty {display:none}` 不能隐藏占位，使用显式 block 高度覆盖。
- 初次挂载先测量真实高度，再卸载远处内容。因此优化稳态 DOM / 堆，**不宣称降低首次打开的峰值**。
- 宽度改变时旧测量失效，临时重新挂载测量，不采用简单高度比例估算；高度改变会更新缓冲范围。
- 已交互（指针/键盘/聚焦）的行保留至会话卸载，以保存上游插件内部状态；不直接删除其 useState，也不建立不完整的状态镜像。代价是大量交互行仍消耗内存。
- 运行期间保留最后一条用户消息起的整个后缀，避免并行工具、正在输出块或消息内部状态被卸载；无人类消息时保守保留全部运行节点。
- 原滚动恢复、加载旧历史和底部跟随仍通过同一组 DOM 锚点工作。
- 一个容器最多一组 IntersectionObserver / ResizeObserver；最后一行卸载时清理观察器和 RAF。缺少观察器或滚动容器时回退原来的全量挂载。

## 测试

服务器执行 `UI_TEST_DEPS=<playwright 所在目录> UI_TEST_BROWSER=chromium|webkit node scripts/test-transcript-windowing.mjs`。

- 测试读取与构建产物完全相同的实现，校验补丁幂等、锚点失败关闭、脚本语法、图谱/hash/index 一致性。
- 同一份 350 行、每行 40 行代码文本数据，比较全挂载与窗口化，数据本身保持驻留。记录 DOM 节点及 Chromium GC 后 JS 堆；不是 macOS WebKit footprint。
- 测试滚动高度不缩水、远处卸载、交互后展开状态保留、活动行保留及完成后释放、窄屏重新测量。
- 加载真实打包的 React、ChatView、ChatNodeSeat 和插件依赖，模拟消息数据；验证首次底部定位、读历史时新消息不抢滚动、前插历史锚点稳定、会话卸载。

## 限制与后续

- 仍保留 O(N) 的轻量锚点和行订阅，不是只保留上下两个总占位的完全索引式虚拟列表。优先避免破坏现有滚动和上游插件状态。
- 单条超长消息、已交互行以及当前活动后缀仍可能很大。
- 浏览器原生查找/全选仅作用于当前挂载正文；完整对话检索应走数据层，不能以 DOM 为权威。
- 缓存淘汰、碎片事件收敛、图像缩略图与首次打开峰值优化不在本次范围。
- Linux Playwright WebKit 不等同于 macOS WKWebView。真实桌面的绝对内存收益仍需单独验收，不从合成场景外推。
