# 问答 60 秒软等待与独立工作继续

## 产品语义

- `ask_user_question` 仍是唯一问答工具。用户没有回答 60 秒后，返回 `status=deferred`，不是 `answered`、`skipped` 或同意。
- 问题继续显示并可回答。超时更新使用相同交互 ID，不能重建草稿或重复插入卡片。
- 模型可继续不依赖答案的工作（包括写代码、测试、查资料），但不能假定用户选择或授权。没有独立工作就结束本轮等待，不能周期轮询或再次提同一个问题。
- 工具审批不参与这个超时流程；提问不收紧也不扩大原有沙箱和工具审批权限。

## 分层与持久化

1. **Interaction**：增加 Deferred 结果状态，返回空 answers、全部 unansweredQuestionIds、原 interactionId 与继续约束，不伪造用户消息或答案。
2. **Session**：新增 `question/deferred`，必须引用 Pending 交互，只允许一次。此事件解除原工具结果的等待屏障，但不会终结问题。已完成工具不再作为待恢复工具重放；另一个全量问题投影保留可迟答交互。
3. **Host QuestionHub**：默认以 `question/requested` 的持久化时间加 60 秒判断到期，后台轮询精度 500 ms。刷新、断线和重启不会重新计算 60 秒起点。计时只存在于活跃工具等待中，取消后不会自行唤醒 Agent。
4. **Tools**：不注入问答专用 `ExplorationGuard`，不按工具名限制继续工作。保留已有工具权限、沙箱、审批、Schema 和生命周期；信息依赖由模型根据上下文判断。
5. **迟到回答**：先保存权威答案，再通过原 Host `session.prompt(mode=steer)` 送入安全边界；用 `question-late-answer:<interactionId>` 作为固定 RPC 身份，既有 Admission Receipt 防重。成功后记录 `question/answer-delivered`。失败保留答案，客户端可重试，启动恢复也会重新交付未确认的 outbox。
6. **同轮迟答**：迟到答案仍通过 Steering 安全边界交付，不修改正在生成的思考。不存在问答 Guard 的同轮锁存或等待下一轮解锁。
7. **Goal**：未回答的 deferred 问题阻止外层 Goal 自动开下一轮，不用持续 Goal 绕开问答等待；模型仍能报告 progress/blocked。

## UI

- 原问答卡片保留，不新增工具或第二套问答面板。
- 卡片显示“等待回答 · 已解除阻塞，可继续不依赖答案的工作；未回答不代表同意”。提示不声称 Agent 此刻一定在运行。
- 相同 ID 的 deferred 帧保留草稿；切换到另一个问题不带走旧草稿。界面现有草稿仅在内存中保存，整个页面重载后的草稿持久化不属于此次已完成能力。

## 不做的事

- 不自动替用户选择推荐项，不保存半成品草稿为正式答案，不默认自动批准。
- 不用字符串判断 Bash 命令“看起来只读”；不把网络 GET 等同无风险。
- 不强行继续无限步，不生成周期任务，不取消或重放原工具副作用。
- 不解除正在执行工具的取消清理，不删除问题/错误审计记录。

## 回归与验收

必须覆盖：超时无答案、回答早于超时、回答/超时竞态、取消不唤醒、Deferred 只记录一次、同 ID 恢复、问题在工具结束后仍待答、待答不额外拒绝独立工作、显式要求审批的调用仍不可绕过、迟到答案持久化/幂等队列、Goal 等待、同请求 UI 更新保留草稿。

Rust 编译和回归仅在 WZU_Server 执行。真实 DeepSeek 验收使用隔离测试会话和只读小文件，不操作用户项目或给生产问题代答。安装包部署须使用新后端；只覆盖前端不会启用此机制。

## 前端解除占位（2026-09-11）

- 收到权威 `deferred=true` 后，同一问答实例自动收起一次，展示“待回答 · 不阻塞当前对话”；普通消息输入框同时恢复。
- 不注销问题、不提交答案、不丢弃同一组件内的选择/文字草稿。手动重新展开后，重复 deferred 帧不会再次强制折叠。恢复出来的 deferred 问题默认收起。
- 复用上游 composer chain 已保持挂载的 fallback；仅在当前胜出组件实际渲染 deferred 问题标记时显示普通输入框。审批或只读子 Agent 接管时无该标记，不被放开。
- 收起仅影响 UI，不改变后端权限。普通消息不被前端自动解释为旧问题答案。跨刷新草稿持久化仍属独立 TODO。
- Chromium/WebKit 回归：超时折叠、展开保留草稿、重复通知、不同问题隔离、恢复默认折叠、普通输入草稿保留、审批仍阻塞、390px 无横向溢出。
