# Source availability

As of 3 October 2026, new XHarness product development is moving to a private
repository. The last public runtime/UI baseline is
`42643e2b6b7e7af164b3123ad0ebd96bf7381bcc`, released as `desktop-v0.2.32`.

This repository retains that baseline, its history, original licenses and
third-party attribution. Existing open-source permissions are not revoked.
This change does not claim exclusive ownership of upstream components or
external contributions.

Public downloads, release notes, issues and the existing desktop update endpoint
remain here. New closed-source versions will be published only after the split
build, signing, native-acceptance and distribution pipeline has been verified.
The transition itself is not a new release and does not change user data.

New product implementation PRs are no longer accepted in this repository. Bug
reports and documentation feedback remain welcome. Public source updates to
Gitee are paused; any future distribution mirrors must contain approved release
assets only, not private branches, tags, source archives or debug symbols.

# 源码公开状态

自 2026 年 10 月 3 日起，XHarness 新产品实现转入私有仓库开发。最后公开的运行时／前端基线为
`42643e2b6b7e7af164b3123ad0ebd96bf7381bcc`，对应 `desktop-v0.2.32`。

本仓库保留该基线、历史、原有许可证和第三方声明；已授予的开源权利不会被撤销，
也不将上游组件和外部贡献改称为项目独占所有。

公开下载、更新说明、Issue 和现有客户端更新入口继续保留。首个闭源版本须先通过拆分后的
构建、签名、原生验收与公开发行链路。此次迁移不是新版本，不修改用户数据。

本仓库不再接收新增产品实现 PR，仍接受问题反馈和文档建议。Gitee 源码同步已暂停；
未来分发镜像只能接收获准的发行产物，不得包含私有分支、源码标签、源码包或调试符号。
