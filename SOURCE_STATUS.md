# Source availability

As of 3 October 2026, XHarness resumes open-source development in
[123123213weqw/x-harness-rs](https://github.com/123123213weqw/x-harness-rs).
This repository is the canonical location for public product source, issues,
pull requests and source CI. The earlier plan to freeze public product source
has been withdrawn. Existing licenses and third-party notices remain unchanged.

Source CI uses standard GitHub-hosted runners. Reopening development is not a
release: the latest published desktop version remains **0.2.32**. Publishing a
new version and replacing an installed application require separate acceptance
and authorization; they are not triggered by this decision.

Private backups, signing keys, credentials and internal deployment records are
not made public. The temporary updater-secret-transfer workflow has been
removed. Public source contributions must not contain credentials, private
conversation data or private deployment records. The private backup repository
is not a source mirror target. Gitee source synchronization remains paused until
it is separately re-enabled from this canonical public repository.

# 源码公开状态

自 2026 年 10 月 3 日起，XHarness 恢复在
[123123213weqw/x-harness-rs](https://github.com/123123213weqw/x-harness-rs)
持续开源开发。本仓库是产品公开源码、Issue、PR 和源码 CI 的主仓库，先前的
公开源码冻结计划已撤回。原有许可证与第三方声明保持不变。

源码 CI 使用标准 GitHub 托管 Runner。恢复开发不等于发版：当前已发布的桌面版仍为
**0.2.32**。新版本发布和本机应用替换须另行验收与授权，不会由本次决定自动触发。

私有备份、签名密钥、凭据和内部部署记录不公开；一次性更新密钥转移工作流已移除。
源码贡献不得包含凭据、私人对话数据或内部部署记录。私有备份仓库不作为源码镜像目标。
Gitee 源码同步暂时仍暂停，须另行从本公开主仓库恢复。
